# Demo stock photos

These JPEG files are copies of the existing Chobe HTML prototype assets. Their
original source URLs are listed in `SOURCES.json`; this seed does not download
new images. Photos illustrate explicitly fictional demo listings and are not
proof of an actual item, its condition, a real seller or a real offer.

The marketplace seed normalizes them with the same image processing service used
for uploads. Some listings reuse the same stock photo, including gallery entries
used to demonstrate cover/order controls. Avatars, shop logos and banners are
simple generated demo illustrations.
